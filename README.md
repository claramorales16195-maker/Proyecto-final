# Plataforma de Diseño de Recetas y Técnicas Culinarias

## 1. Descripción general del proyecto
Una API REST diseñada para que chefs y estudiantes de gastronomía puedan documentar, construir y consultar recetas paso a paso. En lugar de contar existencias, el sistema permite registrar preparaciones base y enriquecerlas progresivamente aplicando diferentes técnicas o variaciones de ingredientes.

## 3. Tabla de requerimientos (Primeros 5 requerimientos a cubrir)

| ID | Requerimiento | Descripción | Prioridad |
| :---: | :--- | :--- | :---: |
| **REQ-01** | Registrar Receta Base | Permite registrar una nueva receta base en el sistema. | Alta |
| **REQ-02** | Consultar Catálogo | Permite consultar el catálogo completo de todas las recetas disponibles. | Alta |
| **REQ-03** | Búsqueda por ID | Permite buscar una receta específica por su identificador para consultar sus detalles mediante el método . | Media |
| **REQ-04** | Añadir Técnica Culinaria | Permite agregar instrucciones de una técnica culinaria específica a una receta existente. | Alta |
| **REQ-05** | Actualizar Parámetros | Permite actualizar la dificultad o el tiempo de preparación de un platillo en el sistema. | Media |
